# Карточка товара «Ананасовый улун» — Teaboom.ru

Тестовое задание на позицию HTML-верстальщик / Frontend-разработчик.
Страница товара с выбором фасовки, рабочей кнопкой добавления в корзину
и счётчиком количества с сохранением состояния.

**Демо:** https://kater-g.github.io/teaboom-card/

## Технологии

- HTML, CSS, ванильный JavaScript
- Без фреймворков, библиотек и сборки: проект запускается открытием `index.html`

## Запуск

1. Клонируйте репозиторий: `git clone https://github.com/kater-g/teaboom-card.git`
2. Откройте `index.html` в браузере.

Интернет нужен только для загрузки шрифтов Google Fonts: без сети страница
полностью работоспособна на системных fallback-шрифтах.
Альтернатива для разработки: Live Server в VS Code.

## Структура проекта

## Функциональность

- **Выбор фасовки** (radio-кнопки): при переключении обновляются актуальная
  цена, старая цена (скрывается, если скидки нет) и артикул; выбранная
  фасовка подсвечивается.
- **Кнопка «В корзину»**: по клику товар добавляется в корзину — меняются
  иконка (корзина -> корзина с галочкой), подпись и оформление кнопки.
  Повторный клик убирает товар.
- **Счётчик количества**: после добавления товара рядом с кнопкой появляется
  счётчик с кнопками «+/−» для изменения количества. «−» до нуля убирает
  товар из корзины. Максимум — 99 штук, на пределе кнопка «+» отключается.
- **Сохранение состояния корзины**: корзина хранится в `localStorage`
  по ключу фасовки (артикулу), состояние переживает перезагрузку страницы.
  У каждой фасовки своё количество: переключение не сбрасывает корзину,
  а показывает сохранённое для выбранного варианта.
- **Данные товара** хранятся в JS-объекте `productData`; фасовки рендерятся
  из данных, а не захардкожены в разметке.
- Цены форматируются по `ru-RU` (326,40 ₽).

## Адаптивность

Корректное отображение на ширинах:

- **1440 px** — две колонки: изображение и зона покупки рядом;
- **768 px** — одна колонка, фасовки в ряд;
- **375 px** — одна колонка, фасовки вертикальным списком (крупные зоны
  тапа), кнопка на всю ширину контейнера.

## Доступность

- Семантика: `article`, `figure`, `fieldset` + `legend` (скрыта визуально,
  но доступна скринридерам), иерархия заголовков `h1 → h2`.
- Кнопка корзины — `aria-pressed`: состояние «добавлено/убрано» озвучивается
  скринридерами.
- Счётчик количества — `aria-live="polite"`: изменение количества озвучивается
  без прерывания текущей активности скринридера.
- Декоративные SVG-иконки — `aria-hidden="true"` и `focusable="false"`.
- Клавиатурная навигация: видимый фокус через `:focus-visible`, переключение
  фасовок доступно с клавиатуры нативно (radio-группа).

## Организация кода

- БЭМ-именование.
- Повторяющиеся значения (цвета, шрифты, отступы, тени, переходы) вынесены
  в CSS-переменные и сгруппированы по смыслу в `_variables.css`.
- JS-хуки — через `data-*`-атрибуты, независимо от классов оформления;
  событие `change` обрабатывается делегированием.
- Инлайн-SVG-иконки с `currentColor`: перекрашиваются вместе с состоянием
  кнопки без дополнительных файлов.

## Архитектура состояния корзины

Корзина реализована как слой данных, отделённый от рендера:

- **Состояние**: объект `{ [variantId]: quantity }`, где ключ — ID фасовки,
  значение — количество. Хранится в `localStorage` для персистентности.
- **Слой хранения** (`cartStorage`): объект с методами `load()` и `save(state)`.
- **Рендер как функция от состояния**: `renderCartZone(variantId)` читает
  количество и решает, как выглядит зона (видимость счётчика, текст кнопки,
  состояние disabled). Обработчики кликов только меняют данные через `setQty`,
  не рисуя интерфейс напрямую.
- **Нормализация данных**: `setQty` приводит количество к целому числу,
  ограничивает максимумом (99), удаляет товар при нуле.

Слой хранения изолирован от рендера, что создаёт основу для интеграции
с backend, хотя полный переход потребует доработок.

## Ветки разработки

Основная ветка `main` содержит тестовое задание в виде, отправленном
работодателю.

Развитие компонента ведётся в отдельных ветках:

- `feature/cart-counter` — счётчик количества товара с сохранением состояния.

## Шрифты, иконки, изображения

- Шрифты: Google Fonts — Zen Antique (заголовки) и Source Serif 4 (текст),
  с системными fallback-стеками.
- Иконки: исходные SVG скачаны в папку `assets` и хранятся как источники —
  в отрисовке они не участвуют. Чистовые варианты интегрированы напрямую
  в разметку как инлайн-SVG: удалены служебные атрибуты, цвет заменён на
  `currentColor`, поэтому иконки перекрашиваются вместе с состоянием
  кнопки без отдельных файлов.
- Изображение товара: исходник с teaboom.ru был низкого разрешения и
  плохо кадрирован, поэтому перед вёрсткой подготовлен заново: обрезан
  по композиции и улучшен по качеству. Улучшенный исходник в формате
  PNG (3 МБ) конвертирован в JPEG (277 КБ) для уменьшения размера файла
  и улучшения производительности загрузки.
